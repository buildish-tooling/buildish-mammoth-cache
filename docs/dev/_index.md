This unreleased development guide is for contributors and maintainers of
Buildish Mammoth Cache. Start with [Contributing](contributing/) for local setup
and the full validation gate.

- [Architecture](../architecture/) explains the cache model, key design, and
  delta protocol.
- [CI provider portability](portability/) records the boundaries for possible
  providers beyond GitHub Actions.
- [Additional build tools](build-tools/) assesses possible adapters beyond
  Gradle and Maven.
- [Maintenance](maintenance/) covers dependency, workflow, and generated-output
  upkeep.
- [Release legal policy](release-legal/) records the deliberately TBD release
  and legal posture.

Nothing under this development route is release documentation.
