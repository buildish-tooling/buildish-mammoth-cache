This patch release fixes Gradle wrapper provisioning on Windows when GnuPG is
selected from `PATH` without an explicit executable override.

- Resolve `gpg.exe` to an absolute path before preparing verification arguments.
- Convert temporary keyring and artifact paths for Git for Windows MSYS GnuPG,
  while preserving Windows paths for native GnuPG installations.
- Use the same resolved executable for key inspection, import, and signature
  verification. Pinned signing keys and signature requirements remain unchanged.

The Gradle and Maven actions continue to use the Node.js 24 runtime. Use the exact
`v0.1.2-rc1` tag during candidate review and `v0.1.2` after final promotion, at
`actions/github/gradle` or `actions/github/maven`. Ordinary source branches omit the
generated executable bundles.
