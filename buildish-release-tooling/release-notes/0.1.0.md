The initial Mammoth Cache release provides Gradle and Maven actions for GitHub Actions.

- Cache Gradle user-home content and provision missing Gradle wrapper JARs with SHA-256
  and detached OpenPGP signature verification before installation.
- Cache the Maven user home, including the local artifact repository and Maven Wrapper
  downloads.
- Restore and publish immutable cache generations in standalone jobs, or exchange worker
  deltas and merge them in a distributed aggregator job.
- Configure cache partitions and behavior through action inputs or shared JSON/YAML
  configuration, with read-only defaults for pull-request events.

The actions use the Node.js 24 runtime. Other CI platforms remain future work.

## Action references and distributions

The Gradle and Maven action paths are `actions/github/gradle` and `actions/github/maven`.
Use an exact published candidate tag such as `v0.1.0-rc1` during candidate review, or
`v0.1.0` after final promotion. Ordinary source branches omit the generated executable
bundles and are not directly installable as GitHub Actions. Moving major/minor tags
are not part of this release.

The release carries a source tarball from the reviewed source commit and an executable
Action ZIP from its materialized child commit. Both archives have detached OpenPGP
signatures and SHA-256/SHA-512 checksum sidecars. Promotion retains the selected
candidate's exact archives and materialized commit rather than rebuilding them.
