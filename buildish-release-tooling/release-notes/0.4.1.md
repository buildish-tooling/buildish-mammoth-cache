# Mammoth Cache 0.4.1

This patch removes the exact Gradle 9.6.1 requirement for the opt-in read-only
dependency layer. Eligible workers stage the restored `modules-2/files-2.1`
artifacts and `modules-2/metadata-*` directories together. Gradle chooses the
metadata format it can use, and Mammoth uses ordinary restore when a required
partition is missing or the seed layout is unsupported.

Existing 0.4.0 cache generations can be reused. Use the same action revision
for prepare and post. Review `v0.4.1-rc1` as the first release candidate and use
`v0.4.1` after final promotion.
