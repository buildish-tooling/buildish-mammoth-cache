# Mammoth Cache 0.1.1

This patch release adds support for Gradle's current signing key when provisioning
and verifying missing Gradle wrapper JARs.

- Pin the current primary key `EA96F38569C044AAEF7FCF732887F479B0B9771A` and its
  dedicated signing subkey `F3FF33E96F18AA62DD580F9651FBF517CE6D6B80`, as published
  on [Gradle's signing-key page](https://gradle.org/keys/).
- Check the signing subkey identity during detached-signature verification and
  retain the previous pinned key for older wrapper versions.
- Skip finalization after preparation fails so the action does not save caches or
  publish worker artifacts from a failed preparation.

The Gradle and Maven actions continue to use the Node.js 24 runtime. Use the exact
`v0.1.1-rc1` tag during candidate review and `v0.1.1` after final promotion, at
`actions/github/gradle` or `actions/github/maven`. Ordinary source branches omit the
generated executable bundles.
